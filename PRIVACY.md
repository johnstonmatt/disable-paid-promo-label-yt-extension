# Privacy Policy

**Last updated: December 2024**

## Overview

"Disable YouTube Paid Promotion Button" is a browser extension that hides the
"Includes paid promotion" overlay button on YouTube videos.

## Data Collection

This extension does **NOT** collect, store, transmit, or share any user data
whatsoever.

## Permissions

The extension requires the following permissions:

- **Host permission for youtube.com**: Required to inject the content script
  that hides the paid promotion button. The extension only runs on YouTube
  pages.

## How It Works

The extension operates entirely locally within your browser:

1. When you visit a YouTube page, a content script runs
2. The script removes the "Includes paid promotion" button elements from the
   page
3. No data leaves your browser

## Third-Party Services

This extension does not use any third-party services, analytics, or tracking.

If this privacy policy changes, the updated policy will be posted in this
