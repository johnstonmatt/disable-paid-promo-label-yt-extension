# Security Policy

## Reporting a Vulnerability

Please report security issues by opening a GitHub issue with enough detail to
reproduce the problem. Do not include private personal data in the report.

## Scope

This extension:

- Runs only on `https://www.youtube.com`
- Does not collect, store, transmit, or share user data
- Does not make network requests
- Does not use remote code

Security fixes that preserve those constraints are prioritized.
